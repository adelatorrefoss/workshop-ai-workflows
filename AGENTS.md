# Agent guidance

- Read the current exercise README before changing files.
- Inspect existing patterns, then make a short plan.
- Stay within the requested exercise and requested feature.
- Run the documented validation command after editing.
- Treat tests and checks as constraints: never delete, skip, weaken, or bypass them.
- Do not expose secrets or commit credentials.
- Stop at the exercise's iteration limit and report any blocker clearly.
- Report changed files, corrective decisions, and exact validation results.
